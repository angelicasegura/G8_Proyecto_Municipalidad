# G8_Proyecto_Municipalidad
# Descubriendo a Nuestras Ecoempresarias

Sistema web desarrollado para la gestión y administración de las ecoempresarias, emprendimientos y actividades relacionadas con la Municipalidad.

El sistema permite gestionar usuarios, emprendedores, emprendimientos, productos, inventario, eventos, reservas, lugares, notificaciones, entregas y diferentes funcionalidades administrativas.

## Tecnologías utilizadas

### Frontend

- React
- TypeScript
- Vite


### Backend

El frontend consume una API REST desarrollada en ASP.NET Core.

### Base de datos

El sistema utiliza una base de datos SQL Server.
